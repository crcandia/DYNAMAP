# Optimizer, architecture and historical comparison inputs

Notebook 16 reads the fixed optimizer and architecture results below, displays the dataframes and exports descriptively named tables. The current three-country method comparison is generated by notebook 22 from [`../../benchmarks/`](../../benchmarks/README.md).

- `optimizer_comparison.csv` and `learning_rate_comparison.csv` contain the predecessor-model experiments.
- `architecture_results.csv` contains the six all-cycle architectures. `architecture_parameters/` supplies their measured tensor counts.
- `benchmark_runtime.csv`, `benchmark_accuracy.csv` and `benchmark_coverage.csv` preserve the earlier author-confirmed method comparison for provenance. These historical CSVs are not used to generate the current manuscript's benchmark tables.

These historical comparisons do not describe the positive symmetric head used in the main results. Fitting notebooks for the original optimizer and all-cycle architecture experiments remain outside this package. The current W-NOMINATE, Bayesian and neural benchmark code and fixed inputs are included in `../../benchmarks/`, with their own reproduction instructions.
